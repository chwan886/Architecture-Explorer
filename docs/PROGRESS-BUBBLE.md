# 可移动演示气泡

演示进度使用独立浮层，不占用架构画布的布局空间。顶部联动栏的「演示进度」可恢复气泡；气泡可拖动、用方向键移动、展开/收起、隐藏和复位位置。浏览器只保存位置及折叠偏好，不保存源码、会话令牌或执行记录。

气泡展示公开的步骤说明和实际执行摘要：当前展示的标题/摘要、业务步骤说明、MCP查询执行情况，以及网页接收/呈现/暂停/失效状态。查询完成不代表网页已呈现；无操作时不会制造进度百分比，也不自动复制Codex内部推理或对话文本。

## 与 MCP 的关系

继续使用现有22个MCP工具和 `AnalysisPresentation`。需要在气泡中讲解时，通过 `present_analysis` 的 `title`、`summary`、`orderedSteps` 发布简短说明，并用实际实体、关系和证据支撑；`show_flow` 的标题及对应业务步骤也能显示。

网页已明确允许并 attach，且已展示当前快照后，同快照的实体搜索、流程、调用路径和源码证据查询会产生简短的运行中/完成/失败记录。首次展示前的查询没有确定页面目标，不广播。多个已绑定页面同时匹配同一快照时，也不猜测投递目标。无需新增AI API或修改用户Codex配置。

执行摘要最多保留40项，仅在当前服务/页面会话的内存中保存。SSE只推送拉取提示，活动内容继续通过原有Cookie会话授权接口读取；退出联动、租约失效或Scope不匹配后，不再接收该查询活动。

## 手动操作

拖动气泡、展开、收起、滚动记录及隐藏，不改变架构图，也不会使正在到达的展示指令发生人工操作冲突。点气泡中的实现源码入口则是明确的人工导航，会暂停旧控制并进入原有代码地图。入口只对当前Scope、有效快照和真实实现开放。

人工操作架构画布后，气泡保留近期记录并说明旧指令已暂停；不会自动取得新版本重试或重新开启联动。历史记录可阅读，但不能被误当作仍在执行的任务，过期解释也不会继续提供有效源码入口。
