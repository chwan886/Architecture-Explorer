# 架构与安全模型

[简体中文](ARCHITECTURE.md) | [English](en/ARCHITECTURE.md)

## 边界

工具是独立 Git 仓库。目标根目录来自本机配置，工具代码、缓存与启动脚本均留在工具目录。全部测试变更在工具自己的临时目标中模拟，授权目标只做读取。服务绑定 loopback，校验 Host/Origin。浏览器不能提交任意扫描目录或任意源码路径。

## 数据管线

配置授权 → 文件清单/哈希 → 编译/模块上下文 → Worker → Schema/交叉引用校验 → 原子快照 → 图投影/查询 → 中文探索界面。

JSON Schema 与 TypeScript 契约位于 packages/schema。Worker 只接收经过授权的相对路径与源码内容。C# 的显式 DLL 引用只读取元数据，不加载执行；Python 使用 ast/symtable，不 import 目标模块。通过子进程隔离、超时、输入输出预算及 stderr 诊断约束分析任务。

ID 以项目 Worktree 作用域和完整语义身份计算，不使用行号。重命名可产生新 ID，收藏可能失效；不能以不可靠历史匹配假装身份连续。每个快照内的关系、证据、文件哈希必须一致。

## 事实与局限

static-confirmed 表示源结构或支持范围内的静态语义被确认，不表示运行时执行过。virtual/interface 调用可以确认声明目标，不能推定实际实例。inferred 表示有证据的推断。当前无运行时采集器，校验器拒绝 runtime-verified 输出。

系统/模块聚合源于目录、程序集和显式配置；不根据代码名称由语言模型猜测职责。聚合边可以还原到原始边与证据。Flow 必须声明分析范围和中断点，不将静态字段访问拼成完整运行时轨迹。

## 缓存与失效

不同项目、Worktree 和配置独立缓存。源文件哈希区分变化，监听防抖合并突发事件，同一作用域串行分析。C# 语义变化可影响同程序集及依赖闭包；Python 导出/导入绑定变化可影响依赖模块。无法证明安全局部更新时扩大扫描范围。

配置、解析器、Schema、引用或编译选项变化必须使相应缓存失效。HEAD/引用变化和启动时清单复核弥补监听漏报。错误不替换最后有效索引；界面状态明确区分空、分析中、同步、过期、失败。

首版每次任务仍两次读取授权文本清单校验内容哈希；持久Worker复用未变AST，语义重绑定范围为受影响语言的合并上下文。尚未达到按脏文件读取与符号依赖精细失效。缓存优化须保留监听失效、同大小/时间戳修改、目录删除和扫描竞态的验证能力。

## 源码读取

证据端点按当前 scope 和 evidenceId 读取。相对路径规范化，逐段拒绝链接/目录联接，真实路径必须在授权根内；限制文件大小并校验内容哈希。任何跨版本不一致都应显示过期，而不能把旧行号当作当前源码。UI 将源码作为文本显示。

## 后续扩展

优先扩展可验证的过程间摘要、Python 容器身份、事件生命周期、显式协议适配器及 Unity GUID 资源关系。其他语言通过同一 Worker 契约接入。规模证明 JSON 索引不足后再引入 SQLite，不提前增加数据库服务。
