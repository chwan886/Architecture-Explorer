# 系统架构与模块协作

## 从整体到源码

首页的“系统总览”使用业务职责定义。候选系统横跨 C# 表现层、协议合同与 Python 规则层，不能把一个文件夹直接当成业务系统。

1. L1 单击系统，查看职责、功能、关键数据、输入输出与人工复核状态。
2. 双击或选择“进入系统”，查看 L2 模块与协作。
3. 进入模块，查看 L3 组件；组件入口打开已有代码地图。
4. 在代码地图探索方法、调用、数据读写和源码证据（L4）。右侧“所属业务系统与模块”可回到职责地图，“返回系统架构”保留原架构上下文。

面包屑返回任一层；返回按钮恢复选择与证据。全局搜索保留原代码搜索能力，系统左栏筛选职责名称。归属不明的源码不会消失，可点击画布底部“尚未归类 · 查看”打开分页列表。

## 两种独立视角

“技术架构”由事实索引中的 asmdef 与源码分组生成。GameDemo02 具有 Game.Domain、Game.Application、Game.Infrastructure、Game.Presentation 四个程序集，另有 Python 服务和配置资源入口。连线来源于真实引用、调用、接口、事件和读写；不以层名称推断依赖方向。

“系统总览”来自工具内独立模型。六个核心候选覆盖访问、资源、人员、探索、装备、战斗；共享支撑与旧路径单列，不混入核心职责。候选仅表示有源码依据的职责划分建议，人工确认状态默认为空。

聚合连线保留原始关系 ID、证据、条件和可信度计数。点击连线后分页查看成员，再打开源或目标符号。类别筛选会重新统计对应成员。字段读写只标“数据读写”，不宣称已经证明跨系统数据传递。

## 首批流程

流程定义由当前代码中的入口、规则、事务、快照和显示步骤组织，使用阶段×职责泳道。每个步骤可定位源码，每段关系独立标记：

| 标记 | 可证明的范围 |
| --- | --- |
| 静态调用确认 | 当前索引中存在静态确认的 calls 边；不证明运行时必然执行 |
| 源码支持 | 同文件有效双端锚点支持叙述位置；不等同完整控制流 |
| 顺序未验证 | HTTP 协议、跨请求、人工叙述顺序；需要运行时追踪补证 |

资源领取流程区分客户端命令、鉴权与幂等、结算规则、SQLite 提交、快照应用与 UI。战斗流程区分开始命令和后续轮询推进，不能把跨请求战斗结算描绘成同一个调用栈。点击下方“步骤之间的关系”查看分支条件和分析限制。

当前没有运行时采集器。确认流程说明不会改变未验证关系的可信度。读取/修改说明来自人工整理的源码锚点与静态事实，尚非自动完成的跨过程数据流分析。

## 持久模型与更新

职责源文件为 `architecture/models/<projectId>/model.json`，独立 Schema 位于 `packages/architecture-model/model.schema.json`。项目 ID 对应配置中的授权项目，不存扫描根目录。新项目没有该文件时返回空业务模型，技术与代码视角仍可用。

模型具有三个独立部分：

- 定义：systems、modules、memberships、flows 与 anchors。
- 复核：reviews，包含目标、Worktree scope、指纹、决策和时间。
- 生成结果：由源索引与模型计算的投影，写入 `.cache` 的独立作用域目录，不提交 Git。

`owner` 用于唯一主要归属。`participant` 与 `shared` 表示参与或共享，只保留关联，不扩张成全部系统两两依赖。冲突 owner、符号缺失、重名歧义、锚点变动均会产生诊断。

“模型”按钮打开 JSON 编辑器。保存采用严格验证、当前索引白名单、完整源码行与内容哈希核对、跨进程锁、乐观版本比较及原子替换。版本冲突保留草稿，请重新读取后合并。系统定义确认、单条归属确认、流程说明确认分别生效，不会批量扩散。可撤回复核。

源码监听沿用既有索引器。源 revision 改变后重新生成聚合关系；模型 revision 改变只重新投影，不调用分析器。人工记录不会被扫描覆盖，指纹不符会显示“需要复核”。不同 Worktree 不共享确认状态；源码证据总来自当前授权工作目录。

网站保存模型通过 SSE 刷新同服务的页面。外部编辑文件后点击“重新载入架构模型”。系统图有独立 viewRevision；过期详情、关系和证据请求返回409，页面清空旧证据后要求重新读取。

## 维护与限制

升级复用原分析器、Schema、图形组件与代码导航，职责投影是新增包。未启用的事件、初始化、资源关系不会被模型补造。未归类实体保留原始代码事实。源码 hash 改变后锚点需维护，不能静默把旧行号当作新证据。

运行、扫描和完整测试命令见 README。所有修改与删除测试在工具临时项目中进行；真实游戏只读验证。模型 Schema 版本与投影版本独立于事实索引版本，升级任一模型/源码版本会使派生投影失效。
