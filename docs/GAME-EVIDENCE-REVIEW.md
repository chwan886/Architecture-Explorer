# GameDemo02 源码证据复核

本轮是 Agent 对真实源码、索引和候选解释的复核。没有替用户写入任何「人工确认」，没有执行游戏模块，也没有把普通引用、参数传递或跨请求关联提升为运行时调用顺序。

## 复核范围

以工具配置授权的 `Assets/Game`、`Server` 为范围。保留六个候选业务系统、20 个模块及其 ID，逐条核对原有 188 个源码锚点的文件哈希、完整行引文、两条原流程的精确实现绑定、关系和限制。原锚点没有漂移。共享 `command`、`settle`、事务入口和跨域协作仍是 participant/shared，没有为了连通系统图而改成多个 owner。

新增 48 个有界完整行锚点，覆盖现在可直接讲清的飞剑伤害、装备、培养、探矿和账号事务路径。最终共有 236 个锚点、131 条可解析归属规则、7 条业务流程，语义层有 34 个简洁分组与 81 个详细步骤。所有新步骤均绑定唯一的主声明、正斜线相对文件路径和真实声明内容哈希；一个方法可以出现在多个语义步骤中。

归属的 `resolved` 只表示当前规则和源码依据可解析。业务系统与解释依然是候选，不能把它解释为已经完成用户业务审查。当前仍有 6915 个源码实体未获得唯一有效 owner，其中包含共享、参与者及未分类实体；这不表示这些实体没有被代码索引扫描，也不表示应该自动给它们强行归属。

## 本轮明确补全的语义

- 伤害「最低 1」是防御减伤后的数值下限，护盾可以使实际生命损失为零。生命值写入在 `sect_combat.damage` 190 行，不能错误解释为每次命中至少扣 1 HP。
- 致死命中提前返回，不继续本次旧附着反应或新附着。存活路径先匹配原有附着，再应用本次 on-hit 状态，避免用新附着触发它自己的反应。
- 装备锻造只入库，没有自动穿戴。穿戴保证同一实例不同时留在多个成员同槽；强化是另一独立分支，且有 +3 上限。
- 主动 train、独立 breakthrough、被动 cultivate 分别有自己的入口与条件。突破同时受修为、大殿、境界、弟子不能超过掌门及材料限制。
- 主动探矿需要最近 10 秒活跃、掌门 explore，每次结算取至多 5 秒的经过时间，再乘矿务堂效率生成工作预算（Lv.4 时为最多 9.5 工作量）；队首未完成时 break 并保留 work。cancel 清队列但不清矿格进度。普通挖矿不会通过 guard 分支解锁守卫格。
- 业务命令拒绝会恢复到 `settled`，保留先前已经完成的时间结算。仅接受的命令递增 revision；只有序列化状态变化才写账号并递增 snapshotSeq；轮询不新增命令幂等回执。

## 信任等级与仍然存在的缺口

在复核快照 `3e98c8924e45d28756706197` 上，81 个详细步骤全部为 `current`，7 个流程的投影诊断均为空。76 条详细关系中：

| 分类 | 数量 | 实际含义 |
| --- | --- | --- |
| `static-confirmed` | 19 | 当前代码索引中存在对应静态调用；不代表某次运行必达。 |
| `source-supported` | 17 | 同一个被选过程内、不重叠语句锚点支持有条件的源码叙述顺序；不是完整控制流或运行轨迹证明。 |
| `unverified` | 40 | 协议、独立请求、动态回调、未知 Python 导入环境或其他有依据的叙述关联。 |

剩余的未验证标记不需要用户逐条点击「确认」来消除。缺少的执行证据应由更精确的绑定、控制流分析或后续运行时追踪补充。人工确认只适用于文字、职责与分组，不能升级底层事实。

当前没有完整 CFG、跨 HTTP JSON 值传播、运行时事件采集与回调分发证明；Python 裸绝对导入依赖未知 `sys.path`，保留候选目标。没有为了图形连贯而连接这些缺口。新增流程也没有替代其他代码实体的原有搜索、调用、字段读写和源码探索能力。

## 验证方式

内容回归覆盖「独立分支不能串成自动执行链」「同方法阶段不冒充自调用」「护盾可零扣血」「致死跳过反应」「旧附着先于新附着」「独立请求边界」「探矿有限预算、break、取消保进度」「命令拒绝回退与有条件持久化」。原两流程的 35 个步骤、6/7 简洁分组与原有调用/请求边界继续保留回归。

本轮定向结果：`architecture-game-model` 与 `game-reviewed-flows` 共 13/13 通过；`semantic-content` 11/11 通过，目录联接/符号链接测试在原生权限下实际执行，无跳过。真实投影核对所有 131 条归属可解析，236 个锚点有效，81/81 详细步骤 current；没有修改目标源码来让测试通过。
