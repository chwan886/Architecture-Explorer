## 范围与限制

- 本轮不调用外部 AI：候选文字经源码整理，规则预览使用本地确定性模板；未来 AI 生成文本的独立版本存储与提供商接入仍为扩展项。
- 没有运行时轨迹、完整 CFG 或跨 HTTP JSON 的值传播证明，不能把静态边解释成必然执行顺序。
- 方法内任何变化都会保守影响映射到该方法的步骤；局部指纹限制复核范围，轻量投影仍在每次索引更新时重算。
- 显式符号重命名/移动及锚点失效需要维护基础映射，不会按相似名称自动重绑定。人工文字保留，不能用一次“重新核验”静默接受变化。
- 大图采用预算、局部展开和独立视口；代码层优先可读性，需要平移/缩放探索。没有新增依赖，原有 ELK 按需 chunk 约 1.43MB，构建仍有其体积提示。
